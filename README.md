## 🚀 Featured Projects

### 🔍 [ChurnLens — Customer Churn Analytics & Risk Predictor](https://github.com/Palak2409/ChurnLens)

An interactive machine learning application that analyses telecom customer data to identify churn patterns and predict customer churn risk.

- Analysed 7,000+ customer records to investigate churn drivers.
- Applied K-Means clustering to segment customers using tenure and monthly charges.
- Built a Decision Tree classifier for churn prediction and evaluated it using precision, recall, and F1-score.
- Developed an interactive Streamlit dashboard featuring data visualisations and business insights.

**Tech Stack:** Python · Pandas · Scikit-learn · Plotly · Streamlit

### 🤖 [DocuChat — AI Summarizer & Document Chatbot](https://github.com/Palak2409/DocuChat)

An AI-powered document assistant that enables users to summarise documents and ask questions about their contents.

- Implemented Retrieval-Augmented Generation (RAG) for context-aware question answering.
- Used ChromaDB for vector storage and semantic retrieval.
- Integrated the Google Gemini API to generate responses using retrieved document context.
- Built an interactive Streamlit interface supporting PDF and DOCX documents.

**Tech Stack:** Python · Google Gemini API · ChromaDB · Sentence Transformers · RAG · Streamlit

## 📄 Research Publication

**Recommendation Method Based on Nutritional Density for Intake Order of Foods Detected by Traditional Machine Learning**

Co-authored research on a Nutritional Quality Score (NQS) framework for ranking foods based on their nutritional composition.

- Evaluated Random Forest, SVM, and KNN models using 10,000 dietary records and 2,039 distinct food items.
- The reported best-performing Random Forest model achieved an R² score of 0.9785 and Spearman correlation of 0.9955.
